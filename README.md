# CV Experiments

A hands-on collection of computer vision work: detection, tracking, segmentation, classification, GANs, and classical image processing. Each notebook is self-contained with code, outputs, and results.

## 📂 Contents

### 🎯 detection-tracking/
Object detection and multi-object tracking: **YOLO** and **YOLOv8** pipelines, classical **vehicle detection** with background subtraction and contours, object **trackers**, and **trajectory** analysis.

### ✂️ segmentation/
Image segmentation experiments.

### 🏷️ classification/
Image classification from first principles to transfer learning: a comparative study of **5 pre-trained CNNs**, neural-network classification, CNN fundamentals, and medical imaging classification on knee MRI (**OAI** dataset, ACL).

### 🎨 gan-image-generation/
Generative adversarial networks: **DCGAN** implementations in TensorFlow and PyTorch (64x64), training experiments, and medical image generation trials (knee MRI synthesis).

### 🖼️ image-processing/
Classical foundations: spatial **filters**, **Fourier transform** analysis, geometric transformations, and image data extraction pipelines.

### 🔤 ocr-captioning/
Text and vision-language: **OCR** pipelines and **image captioning** with encoder-decoder models.

## ⚙️ Stack

Python · PyTorch · TensorFlow/Keras · OpenCV · Ultralytics YOLO · NumPy
